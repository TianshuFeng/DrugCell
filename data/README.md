# Data Folder

Due to the large size of the dataset, most files in this folder are stored in the `data.rar` archive available in the **Release** section under the name `data`.

To restore the full dataset:
1. Download `data.rar` from the Release page.  
2. Extract its contents into the current `data` folder.  

**Note:**  
Inside the compressed package, there is an empty folder named `Desktop`.  
If a folder named `Desktop` (containing three files) already exists under `data`, simply choose **Merge** when prompted about duplicate folder names.
